🎯 Detection & Scoring API
GET /toggle
Start/stop detection on all cameras
GET /reset
Reset all cameras and start new round
GET /hits
Get all hits from all cameras
GET /hits/{cam_id}
Get hits for specific camera (e.g., /hits/0)
GET /get_scoring_config
Get current scoring configuration
POST /set_scoring_config
Update scoring rules (4-ring, bull hole bonus, shots per round)
📹 Camera Control API
GET /camera_urls
List all connected cameras
GET /camera_info/{cam_id}
Get camera status (zoom, rotation, exposure, etc.)
GET /video/{cam_id}
Live video stream with detection overlays
GET /raw_video/{cam_id}
Raw video stream without overlays (for calibration)
GET /set_zoom/{cam_id}/{value}
Set zoom level (1.0 - 4.0)
GET /adjust_zoom/{cam_id}/{delta}
Adjust zoom by delta (e.g., +0.1 or -0.5)
GET /set_rotation/{cam_id}/{angle}
Set rotation angle (0, 90, 180, 270)
GET /lock_exposure/{cam_id}
Lock camera exposure
GET /unlock_exposure/{cam_id}
Unlock camera exposure
GET /lock_white_balance/{cam_id}
Lock white balance
GET /unlock_white_balance/{cam_id}
Unlock white balance
GET /set_white_balance/{cam_id}/{temp}
Set white balance temperature (2800, 4000, 5500, 6500)
GET /optimize_camera/{cam_id}
Auto-optimize camera settings
🎯 Calibration API
POST /set_calibration
Save calibration points (camera_id, center, bull, outer)
⚙️ Configuration API
GET /get_config
Get complete system configuration
POST /set_recording_config
Update recording settings
POST /set_shot_directory
Set shot recording directory path
POST /set_advanced_config
Update advanced detection settings
🚀 Quick Start Guide
  1. Configure Cameras - Go to Camera page, set zoom/rotation for each camera
  2. Calibrate - On Camera page, click 3 points on target preview
  3. Configure Match - Go to Settings, set scoring rules and recording options
  4. Start Shooting - Return to Main page, click "Start All Cameras"
  5. View Results - Scores appear in real-time, view saved rounds in Rounds page
